# Changelog

## 1.0.1 — 2026-11-03

- Match the empty-view button's font size, line height, border, corner radius and spacing to VS Code's native Ports view.

## 1.0.0 — 2026-11-03

- Initial public release of Reverse Ports with a monitor and return-arrow icon.
- Manage SSH reverse forwards in a bottom panel styled after VS Code Ports.
- Add a remote port and optional local destination inline; edit either endpoint independently.
- Save with Enter or an outside click; cancel with Escape. Running forwards restart after edits.
- Count running forwards in the panel badge and show errors in notifications and tooltips.
- Open remote proxy terminals, inject proxy variables into matching workspaces, and copy three export lines.
- Support Chinese and English, existing SSH configuration, keys, agents and ProxyJump.
